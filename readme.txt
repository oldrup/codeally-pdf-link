Adds a native WordPress Block Editor block that links to PDFs with Media Library thumbnails.

== Description ==

Codeally PDF Link adds a native WordPress Block Editor (Gutenberg) block for selecting a PDF from the Media Library and displaying a link with its thumbnail preview. It is not a widget for Elementor, Divi, or other third-party page builders.

The block uses the thumbnail generated by WordPress when the PDF is uploaded. If the server cannot generate a PDF preview, WordPress displays a generic media icon instead.

The block includes four styles: Link Top, Link Center, Link Bottom, and Link Below. It supports text and background colors, font size, and padding. The link includes screen-reader text identifying the file as a PDF.

Optional CSS classes `cdly-pdf-link--small`, `cdly-pdf-link--medium`, `cdly-pdf-link--large`, `cdly-pdf-link--x-large`, and `cdly-pdf-link--xx-large` size the thumbnail using the corresponding theme font-size preset. Use `--cdly-pdf-width` for a custom size or if your theme does not define the needed preset.

The plugin has no external runtime dependencies. PDF thumbnail generation depends on the image-processing support available to WordPress on the server, typically Imagick and Ghostscript.

Developed by [Bjarne Oldrup](https://oldrup.dk/) and sponsored by [Codeally](https://codeally.dk/).

== Installation ==

1. Upload the `codeally-pdf-link` directory to the `/wp-content/plugins/` directory, or install the plugin through the WordPress Plugins screen.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Add the **PDF Link** block and select a PDF from the Media Library.

= CSS custom properties =

Set these properties on the block or an ancestor element to customize the thumbnail and spacing:

* `--cdly-pdf-width` — thumbnail width (default: `2.5em`).
* `--cdly-pdf-gap` — space between thumbnail and link text (default: `0.5em`).
* `--cdly-pdf-shadow` — thumbnail drop shadow.
* `--cdly-pdf-hover` — additional thumbnail filter on hover (default: `saturate(115%) contrast(115%)`).

For example, add CSS to your theme:

    .wp-block-cdly-pdf-link {
        --cdly-pdf-width: 4em;
        --cdly-pdf-gap: 1em;
    }

== Accessibility and compatibility ==

The PDF file type is identified by a visually hidden label. The thumbnail is a clickable hit area for the same link as the title; the block does not add a duplicate link. The visible keyboard focus outline is preserved.

Keyboard navigation and screen-reader behavior have been tested with Windows Narrator and NVDA. The generated front-end markup is valid HTML, and the plugin passes WordPress Plugin Check.

== Frequently Asked Questions ==

= Does the plugin generate PDF thumbnails? =

No. WordPress generates PDF thumbnails when files are uploaded, provided the server supports PDF image processing. The plugin uses the available thumbnail or WordPress's generic media icon.

= What happens if I deactivate the plugin? =

The saved link remains available on the front end, including its visually hidden PDF label. The thumbnail is generated with CSS, so it disappears when the plugin's stylesheet is no longer loaded. In the editor, WordPress may report that the block is unavailable and ask whether to keep or remove its content; keeping it preserves the saved link.

= How do I customize the thumbnail size and spacing? =

Add one of the optional size classes under the block's **Advanced** settings > **Additional CSS class(es)** to use a theme font-size preset. The theme must define the matching preset. To set a specific width independently of font size, set `--cdly-pdf-width` on the block or an ancestor element, for example `--cdly-pdf-width: 120px;`. Use `--cdly-pdf-gap` to customize the space between the thumbnail and link text.

= Which themes has the plugin been tested with? =

As of September 2026, the plugin has been tested with Twenty Twenty-Five, Greyd, and Ollie (Full Site Editing themes), and Blocksy, Kadence, and GeneratePress (classic themes).
